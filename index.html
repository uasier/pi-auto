安装并启动 Herdr

        
本工具只连接 Herdr pane。请先安装 Herdr，再在 pane 里打开 Pi / Claude / Codex / Grok。

        

          

            
1. 安装 Herdr

            macOS / Linux
          

          
在终端执行官方安装脚本：

          
curl -fsSL https://herdr.dev/install.sh | sh

          
        

        

          
2. 启动并打开 Agent

          
    
            
  1. 终端执行 herdr，或打开 Pi Agent Desktop
    2. 
            
  2. 在 pane 里启动 pi / claude / codex / grok
    3. 
            
  3. 回到本应用，点「重新检测」
    4. 
          

        

        

          
3. 确认已连接

          
左侧横幅变成「Herdr 已连接」，会话列表会出现 pane。普通 VS Code / Terminal.app 里的 CLI 无法接入。

        

        

          
          
          
        

      

    

    

      

        
        
怎么用

        
上边看终端，下边写话。计划、循环、提交都收在右侧抽屉里。

        

          

            1
            

              选会话
              
点「会话」，选一个 Herdr pane。必须是 Herdr 里开的 Pi / Claude / Codex / Grok。

            

          

          

            2
            

              直接发一句话
              
下方输入框写内容，点右下角「发送」，或 ⌘ / Ctrl + Enter。

            

          

          

            3
            

              排任务计划
              
点「计划」→「加入计划」或「导入」。计划只属于当前选中的窗口，换会话不会带走任务。

            

          

          

            4
            

              开始循环
              
点「开始循环」：空闲后自动下一条。做完可单独再走一轮提交；上下文超过阈值会先压缩。执行中若连续 5 分钟画面差异不到 1%，会自动输入「继续」唤醒卡死的 CLI。打开「Jev 续跑」后，每轮会要求列出下一步，由 Jev 选定一项再自动续跑。
