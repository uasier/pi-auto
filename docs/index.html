左边选，中间看，右边排。

发送

输入后点发送，或 ⌘ / Ctrl + Enter。优先走 Herdr agent.prompt，不行再向 pane 输入。

计划

加入计划或导入文本。计划只属于当前选中的窗口。

循环

空闲稳定后发下一条。可设次数、空闲秒数，以及上下文百分比。超过阈值会先压缩。

卡住

循环中若 5 分钟内终端变化不到 1%，且不是 idle，会输入「继续」。

续跑

每轮结束后列出下一步，由决策模型选一项再发。置信不够或选择停止，就不再续。

提交

任务和续跑都结束后，单独再发一轮 git commit。不 push。

密钥在系统菜单里。

⌘ , 打开密钥设置。检查用的是当前输入，不必先保存。Key 留空用环境变量，地址留空用默认值。

用之前。

  1. 安装并启动 Herdr。
  2. 在 Herdr pane 里运行 agent。普通终端无法接入。
  3. 确认本机有 ~/.config/herdr/herdr.sock。

没选会话时，中间是一局贪吃蛇。手动、Jev、Laya 都要点开始才走。
